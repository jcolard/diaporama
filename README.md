# 🌟 Diaporama des 80 ans — Danielle (1946 - 2026)

Diaporama souvenir conçu pour les 80 ans de Danielle.

👉 **Accéder au diaporama en ligne :**  
**[https://jcolard.github.io/diaporama/](https://jcolard.github.io/diaporama/)**

---

## 📽️ Caractéristiques
- **127 photos** souvenirs organisées avec leurs légendes et dates.
- **Défilement automatique** en boucle (9 secondes par photo, 6 secondes pour le carton titre).
- **Zéro dépendance externe** : polices et styles intégrés localement, fonctionne avec ou sans connexion Internet.
- **Compatible tous écrans** : vidéoprojecteur, TV, PC portable, tablette et smartphone.

---

## ⌨️ Raccourcis & Contrôles
| Touche / Geste | Action |
| :--- | :--- |
| **`F`** | Plein écran (Échap pour quitter) |
| **`Espace`** | Mettre en pause / Reprendre le défilement |
| **`→`** / **Page Down** / **Swipe gauche** | Photo suivante |
| **`←`** / **Page Up** / **Swipe droite** | Photo précédente |
| **`T`** | Basculer entre le thème clair (*Papier*) et sombre (*Sapin*) |
| **`L`** | Afficher ou masquer les légendes |

---

## 💡 Conseils pour le jour J
1. Brancher l'ordinateur au vidéoprojecteur ou au téléviseur.
2. Ouvrir le lien dans Google Chrome, Edge ou Firefox.
3. Appuyer sur **F** pour passer en plein écran.
4. Penser à désactiver la mise en veille automatique de l'écran avant le repas.
